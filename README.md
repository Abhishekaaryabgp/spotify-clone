# 🎵 Spotify UI Clone

A modern Spotify-inspired frontend clone created using HTML and CSS.

---

## ✨ Features

- 🎧 Spotify-inspired modern UI
- 📱 Responsive layout
- 🖥️ Desktop view support
- 📲 Tablet view support
- 📺 Fullscreen layout
- 🎨 Clean dark theme interface

---

## 🛠️ Tech Stack

- HTML5
- CSS3
